See exactly what Supabase hands your app.

This Spring Boot app signs you in with a Supabase project over OAuth 2.1, then shows the tokens it receives and what each part means.

  1. You're sent to Supabase. Spring starts the authorization code flow with PKCE.
  2. You sign in and approve. Supabase has no login screen of its own: it sends you to this app's consent page.
  3. Spring receives the tokens. It checks them against Supabase's public keys and shows them to you here.
