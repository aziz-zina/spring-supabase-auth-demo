Sign in with Supabase

This Spring Boot app is an OAuth client of your Supabase project. Clicking the button starts the authorization code flow with PKCE:

  1. Spring redirects you to Supabase's /auth/v1/oauth/authorize.
  2. Supabase redirects you to the consent page (/oauth/consent), served by this app, not by Supabase.
  3. You sign in and approve. Supabase sends a code back to Spring, which exchanges it for tokens.
